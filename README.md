# Student Academic CGPA & Grade Predictor

A modular Python CLI tool for tracking VIT course marks, evaluating attendance eligibility, and predicting required examination target scores.

## Directory Structure

```text
cgpa-grade-predictor/
│
├── src/
│   ├── __init__.py
│   ├── calculator.py   # Grading and attendance logic
│   ├── predictor.py    # Target mark predictor & procedural guidance
│   └── storage.py      # OOP models & local JSON persistence
│
├── tests/              # Unit test suites
├── main.py             # User interface entry point
├── requirements.txt    # Project dependencies
├── statement.md        # Detailed problem statement
└── README.md           # Project documentation
```

## How to Run

1.Clone the repository:

```bash
git clone https://github.com/aarushshrotriya/cgpa-grade-predictor
cd cgpa-grade-predictor
```
2.Execute the CLI application:

```bash
python main.py
```
